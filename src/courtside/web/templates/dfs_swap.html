Swap your own entries

  1. On DraftKings open Lineups, then Edit Entries for this slate, and download the CSV.
  2. Choose that file here. It is read on this machine and not saved.
  3. Download the edit file and upload it on the same DraftKings page yourself. Courtside never signs in to DraftKings or changes entries.
{% if v.at %}{% endif %}

Cells are read as “Name (ID)”, DraftKings’ own format, or as bare numeric IDs. Which ID DraftKings expects for a new player has not been confirmed with a real upload yet: new cells use the ID from your own file’s player list, and locked or unchanged cells are written back exactly as DraftKings wrote them. If DraftKings rejects the file, try Same file, IDs only.

Projections are simulated, not results. A swap is only proposed when a ruled-out player has to go or the projection gains at least half a point. Downloads are plain CSV files you upload to DraftKings yourself.{% if v.seconds %} Solved in {{ v.seconds }} s.{% endif %}
